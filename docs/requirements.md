# 需求說明

## 這是什麼
一個不用登入的匿名聊天室。所有人在同一個聊天室裡。

## 誰會用
任何知道網站連結的人都可以進來用, 可以用電腦, 也可以用手機來操作。

## 使用的流程
1. 打開網頁
2. 輸入一個代號
3. 進入聊天室，看到其他人的訊息，也可以送出訊息
4. 瀏覽器會記住上次的代號，下次打開自動進入
5. 想離開時按「離開」（會先確認一次），離開後記住的代號會被清掉

## 畫面上要有
- 誰在線上
- 有人進來或離開時要有提示
- 在線人數與名單（電腦版固定在右側，手機版點「N 人在線」展開）
- 訊息的發送時間；自己的訊息靠右、用不同顏色
- 新人進來時看到最近 50 則歷史訊息
- 斷線時顯示「重新連線中」，自動重連並補上漏掉的訊息
- 分頁在背景時，標題顯示未讀訊息數

## 不需要的
- 註冊、登入
- 傳圖片或檔案
- 檢舉、管理者刪除訊息、關鍵字自動過濾
- 提示音、瀏覽器系統通知
- 改名功能（要換代號就離開再進來）
- 私訊、多個聊天室

## 新增功能（原本沒要求、我另外想到並做好的）
- **資料庫端防洗版**：同一個代號 2 秒內只能送 1 則，由 Supabase 的資料庫規則強制執行（不只是前端擋）。前端會顯示倒數，輸入框裡的文字會保留，冷卻結束後可以再送。
- **資料庫端拒絕偽裝代號**：含看不見的字元（零寬空白、方向控制字元等）的代號會被資料庫拒絕；比對重複時，全形與半形、大小寫視為相同。
- **分頁標題未讀數**：分頁在背景時，標題會變成「(3) 匿名聊天室」，回到分頁後清掉。
- **離開前確認視窗**：按「離開」後跳出確認視窗，確認鈕是「確定離開」；預設焦點在「留下來」，避免誤按。
- **記住代號並自動進入**：重新整理或下次打開，不用重新輸入代號。
- **斷線自動重連並補訊息**：斷線時顯示提示並停用輸入，恢復後補上漏掉的訊息；手機回到前景時也會檢查連線。
- **「有新訊息」按鈕**：往上翻舊訊息時有新訊息，不會被強制拉到底，改顯示按鈕讓你選擇何時跳到最新。
- **字數提示**：接近 500 字上限時顯示「剩 N 字」。
- **訊息一律當純文字顯示**：訊息裡的 HTML 或程式碼不會被執行。
- **資料庫權限**：任何人只能讀取和新增訊息，不能修改或刪除。
